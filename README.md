# Make the AI Judge Feel Curious

A tiny program that writes one short, calm, intriguing text to `/output/entry.txt` for the make.fun bounty [make-the-ai-judge-feel-curious-20261122-2311](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

## Run

```
python3 main.py
```

`main.py` (Python 3.13, standard library only, deterministic, no network) writes the entry text to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that environment variable is set.
